# Hacktober Fest 2026

Title: Frank.io

We decided to incorporate the theme of Fusion through the literal fusion of parts of one big drawing that players work on. This is a multi-player game where everyone get assigned a body part ie. arm, leg, torso, head. Played on one device but can be split into tabs or reloaded for the next player. Once everyone has finished drawing, the limbs get fused together to create a final image - just like Frankenstein's monster. Players can add colours and Halloween-themed stamps to their drawings to make them extra.

# How to run:

    uv must be installed
    clone the repository
    cd into cloned rep
    run uv sync, and then run uv src /app.py
    navigate to provided url in the terminal and start playing!

# NixOS:
```
nix-shell
cd src
flask run
```
